# 可比较的 Snake Harness 与后续 GEPA 边界

## 版本、隔离与回滚

`packages/games/src/arcade/snake-harness.ts` 是唯一实验策略入口。ID 为 `snake-harness-{a,b,c}-v1`；物理规则版本继续 `snake-realtime-v2`，通用请求协议继续 `decision-arena-arcade-v4`。A 的指令文本与代表性观察/候选有 SHA256 回归断言。不得在这些 ID 下继续调参；修改后新增版本并重新分配独立验收集。

请求创建参数增加 `config.snakeHarnessVersion`。服务端白名单仅接受贪吃蛇和三个完整 ID，新局缺省 A；实验脚本显式写入每场版本。保存后的配置、在途请求、decision事件和回放保持版本。暂停/继续/恢复不改变版本，未知付费结果仍要求明确重试。其他游戏不接受该配置。

旧回放缺字段仍缺字段，旧事件不重写。旧局之后产生的新请求采用冻结A并在新事件标识；此前实际使用过的prompt仍按原事件保留。旧回放克隆的新局明确A。公共回放只额外允许这个枚举字段，内部观察检查点不出现在公共回放。

回滚无需迁移数据库或删除对局：**下一局**创建时传 `snake-harness-a-v1`，或在普通创建页使用缺省A；进行中的局保持原版本。如果实验失败，不修改默认值。不要用git回退新版本解析代码去运行仍包含B/C的已存储对局，也不要重标历史来伪造“已回滚”。

## 数据路径

真实请求仍使用 Arena 当前登录会话 → API ownership检查 → 已冻结的本人ModelProfile → runner凭证归属与Bamboo连接检查 → provider适配器。脚本不读Key，不导入另一个项目的配置，不使用内部owner请求头。

runner 仍从游戏adapter生成原候选；A/B传同一原观察，B只替换instructions。C把公开可见的观察投影传给纯函数，移除重复的字符棋盘但保留所有身体坐标、食物、方向、时间和当前按键；每个候选提供完全一样的几何字段。C没有游戏state、RNG、futureFood或执行API，无法调用寻路/额外输入。上一动作效果是两次观察的事实差值，不宣称全部位移都由该动作单独造成。

原provider仍将动作列表映射成 m0/m1/m2 并校验返回choice，真实方向由模型选择。duration仍100ms，反向仍排除，所有合法危险动作仍可选。所有实时请求的thinkMode固定never；实际是否返回thoughtUsed以服务商遥测为准，未返回单列，不能当0。

实验driver每场使用自然结束的单AI会话，不增加单步或暂停评分路径。完成后仅在内存重放原输入，校验帧/终态，输出数值摘要；原私有replay仍由现有R2/DO机制保存。身份、钥匙、raw请求、思考、私有地址不进入实验报告或公共回放。

## 以后最小 GEPA 接入

本次不安装、不运行GEPA，也不把当前小样本参考收益称为迁移成功。需要自动化时先复用这一组接口与有限预算driver：

1. **允许优化**：策略指令文字、可见状态的字段顺序/命名/精简、对所有候选一致的静态几何表达。候选ID、动作集、合法性校验、速度、计分、超时、配额、凭证与请求调度为不可优化边界。生成的状态投影只能接受可见DTO，不接收完整state或随机源；白名单及无副作用契约测试先通过再允许调用。
2. **训练反馈**：保留死亡或长时间无得分前最近20个决策，必要时保留跨越一次食物更换的窗口；每条包含观察tick、已有queued、选择/生效tick、响应耗时、期间真实移动数、丢弃与终局。按“观察错误/陈旧状态/输入语义/基础设施”分开。保留失败局，不只反馈高分录像；长循环保留至少一个完整重复状态周期及起止分数。思考不是必要输入，不能将密钥、原始请求或另一玩家隐藏信息送给coach。
3. **选择与独立验收**：开发种子可反思，selection用于选候选；一次冻结一个candidate。release种子不供反思、选候选或重试，使用真实时钟、同预算、交错配对及预先指定重复。未知请求/暂停/服务错误停止并单列，不记0分、不自动重发。不能用 paused诊断分数替代realtime分数。
4. **拒绝退步**：沿用预声明的食品均差、配对区间、原规则胜负、重复波动和执行/隐私门槛；不过即保留A。新策略若通过还需人工确认默认切换，发布manifest记录源码/指令hash、规则、模型参数、种子组hash、报告和预算；运行中的局永远不随全局默认更新。

这能先检验“文字策略是否帮助”和“表达方式是否帮助”。延迟只作为实际性能因素测量，本轮没有随机化网络延迟，不能据相关关系声称已估计延迟的独立因果效应。
