# Snake A/B/C 预声明（开始任何预实验前）

日期：2026-10-17。范围仅 `snake-realtime-v2`。默认 A；本实验不部署、不发布社区，不改变已有用户设置。参考项目只读，不使用其密钥、数据库、任务或训练种子。

## 固定对照

| 版本 | 不可变 ID | 相对 A 的唯一实验差异 |
|---|---|---|
| A | `snake-harness-a-v1` | 当前 `decision-arena-arcade-v4` 指令逐字冻结，原观察 |
| B | `snake-harness-b-v1` | 只换策略指令：提前转向、已排队方向不需要确认、迟到与增长语义、以吃食物为目标避免空循环 |
| C | `snake-harness-c-v1` | B 的同一指令；重排当前可见状态，删除重复字符棋盘，以完整有序身体表示占用；所有合法候选逐一给静态邻格、身体索引、是否尾格/食物、距墙格数；前后真实观察差值 |

棋盘20×20、3格/s、60Hz、每20tick一格、120s、每轨道300次、请求间隔至少500ms、最多一个在途、100ms方向输入及全部原计分/终局/合法性/调度/传输不变。A/B 的实际 `state`、候选标签/顺序及请求参数相同，只有 `instructions` 不同。C 不模拟未来、不读 RNG、不推荐/排序/过滤方向。禁止本地代打、随机回退、自动避障及“为了成绩”调慢或暂停。关闭思考，保留所选模型的其他参数。

历史没有版本字段的记录保持缺失，不重新标版本；其未来请求按冻结 A 兼容执行。新局固定版本，不存在局内切换命令。历史已发生的混合 prompt 事件保持原记录。

## 数据与顺序

`seeds.json` 在本预声明时生成。1 个 development 种子仅用于预实验；20 个独立 acceptance 种子仅用于最终评测。第 0/4/8/12/16 个验收种子预先指定各重复一次，不加入独立样本置信区间。种子不按初始食物筛选；同种子路径分歧会影响后续食物，不能声称完全相同食物序列。

每个种子内 A/B/C 同一模型，顺序按 ABC、BCA、CAB 轮换；模型在批次内交错。全部独立单 AI 实时会话，沿用账户活动配额，不并发制造负载差异。最终主模型预选 StartLux，Jev 先用于独立预实验及接口可用性检查，不混合模型来抬高均分。若主模型不可用，不偷偷更换模型或种子；记录阻塞。

预实验6局：上述 development 种子 × A/B/C × 已有 StartLux SystemOne 与 Jev1.13 OpenRouter 配置；各最多300次，合计硬上限1800次。每局最多120s游戏时间，允许在途尾部最长120s。结束后用实测请求量/墙钟时间固定正式有限预算，再启动任何验收。模型配置 ID 只放本地计划（无 key），发布报告标明请求/实际模型。

预算控制以每场最坏300次预留，完成结算后释放未用余额。暂停、API失败、未知计费结果、重启、规则不符或回放不一致停止整个批次，不能把未完成局记0分或自动重试。正式预算耗尽则未完成验收，不降样本门槛，不扩大预算追成绩。任何重新启动只允许读取已知会话并核对，不重发未知付费请求。

## 事先固定的发布门槛

两候选分别对 A 做相同种子配对，独立集至少20对全部有效，未达数量不能发布。主指标为食物数，次指标为平台原规则（食物、再存活tick）的胜/平/负。

候选必须同时满足：

1. 独立集 candidate−A 平均食物差至少 **+0.5**。
2. 固定随机种子的10,000次配对bootstrap，**97.5% 双侧 percentile 区间下界 > 0**（对B、C两个比较采取保守多比较处理）。这是有限样本估计，不当作分布无关保证。
3. 原平台比较净胜局数至少为0；重复子集平均食物差不为负，重复运行波动单独完整报告。
4. 无新增错误、越预算、未知执行、回放偏差、动作替换或隐私问题；按实际指标报告模型未返回的思考/用量信息，不能假定为0。

若两候选都通过，优先独立集平均食物更高者；同均值选改动更少的B。若未通过、发生不可控服务/基础设施错误或证据不足，默认保持 A。不会降低门槛、删不利种子、重复挑局或在看过验收后修改B/C。后续版本必须另命名、另建未用验收集。

## 统计与证据

每局保留脱敏元数据与逐决策数值：食品/原分/存活tick/结束原因、最大连续无得分成功移动数、完整有序身体+方向+食物再次出现的次数、请求/错误/丢弃、延迟中位/P95、观察到结算/生效的tick及成功移动数、model选择与input一致、规则/Harness版本、请求与实际模型、thoughtUsed和返回的数值用量。

旧事件只有结算tick，不是精确HTTP到达tick；终局后会话tick冻结。报告不混淆结算/按键接受/蛇下一格实际移动。完整回放仅内存重放校验与本地原私有存储，实验输出不落盘完整回放、请求、思考、Key、Cookie或私有URL。开发、独立验收、重复运行三类结果分表，不用历史非配对局充当A的正式对照。

主要假设源于 `trace-audit.md` 的迟到转向及 queued 重复模式。实测若无提升，直接保留A并报告；本轮不移植GEPA。
