# Arena 俄罗斯方块 V8：真实配对实验结果

日期：2026-10-18。**本次在既有 StartLux 配置上观察到小样本改进，但代价显著，保持旧版默认、V8 可选。** 六个预先固定的独立种子，平均消行数从 0 提高到 3.33；同一种子重复时 V8 从 1 行变为 4 行，不能承诺每次表现相同，也不能推广为模型能力排名。

实验前冻结的[协议](protocol.md)、[预实验复核](pilot-review.md)、可计算的[脱敏成绩与源码清单](results.json)、[接入与复现说明](../../tetris-v8-harness.md)。参考项目只读，未使用其密钥、数据库或运行其任务。其暂停式实验的 708.33 分不是 Arena 成绩，冻结目标提示也没有纳入通用 GEPA 自动进化。

## 环境、版本和预算

- 使用 Arena 已有的 `new-api · StartLux 27B（本地）` 配置；请求与所有实际返回的模型均为 `startlux-decision-27b-autothink`。全部 801 次真实返回均报告未使用思考；`think_mode=never`，原配置中的预算参数保留但不启用思考。
- A：`tetris-harness-baseline-v1`，原 Arena 文本观察与直接按键请求，指令及输入规则冻结。
- V8：`tetris-harness-v8-realtime-v1`，冻结源策略原文＋明确的 Arena 适配补充，结构观察、完整 PNG、全部 40 个条件落点后果、Decision 目标记忆、Decision 原生按键。
- 原生 `tetris-realtime-v1`：10×20＋两行生成区、7-bag、SRS、原重力/锁定/DAS/ARR/计分规则，60Hz 连续运行。每局 120 秒、最多 300 次请求、启动间隔至少 500ms。目标调用也占预算，模型等待不暂停物理。
- 1 组预实验、6 组独立验收、1 组重复，共 16 局。总上限 4,800 次，实际 801 次（预实验 88、验收 623、重复 90）。无自动重试、缺失配对或中途改策略。
- 源码清单 SHA-256：`2dc0525544888a2ceb311fefd7c6a3bdfd90aa3d6b18a6208e87de4cd72fc506`，预实验和最终批次一致。实验后只修正了回放面板的 CSS 对比度，没有更改模型、规则、执行器或实验脚本。

两组是**相同种子、时间及请求次数上限**，不是相同实际调用次数、token 或花费。提前顶出的原版自然停止调用。hold 和取块进度可以分歧；相同种子不意味着模型观察到相同局面或经历相同延迟。首版 V8 仅支持能接收图片的 System One 协议，本轮未检验 Jev 的 V8 能力。

V8 的 452 次接受包含 120 次目标更新和 332 次原生按键，目标更新不是游戏输入。其 9 次丢弃中，3 次发生在等待时换块，6 次发生在达到时限后；A 的 3 次丢弃均在游戏结束后。危险但仍合法的动作照常执行，不做自动避险。

总 input_tokens 约 31 倍，是服务报告用量，**不是费用倍数**：接口未返回可据此核实的价格。模型内部如何统计多候选及视觉 token 也未单独验证。改进不能被描述为“免费提高分数”。

完整 PNG 经实际 HTTP 请求发送，图像哈希与尺寸来自发送内容；源码和传输测试验证目标、按键两阶段都携带图像。成功返回仍不能证明上游实际利用了图像。本实验是完整链路对照，无法单独归因于视觉、落点事实、目标记忆、策略或耗时。

## 真实轨迹：哪些问题改善了，哪些仍存在

以下 `返回 tick` 是 Runner 结算 tick，并不是单独记录的 HTTP 抵达时间。`—` 表示没有原生输入生效。所有数据来自本人已完成的回放，在内存中按原生输入重建；完整私有回放和原始模型响应没有写入 docs。

**旧版确有连续硬降，而不是执行器把横移改成硬降。** 独立 101 的 [A 对局](http://127.0.0.1:5091/zh/arcade/arcade-a37afa16-1f41-449c-9e87-c36b85945f96) 最后六次选择全为 `hard-drop:100`：

| 事件 | 观察 tick | 返回 tick | 生效 tick | 实际结果 |
| --- | ---: | ---: | ---: | --- |
| #15 | 188 | 197 | 198 | 第 7 块锁定并换块，无消行 |
| #17 | 219 | 229 | 230 | 第 8 块锁定并换块，无消行 |
| #19 | 250 | 259 | 260 | 第 9 块锁定并换块，无消行 |
| #21 | 281 | 291 | 292 | 第 10 块锁定并换块，无消行 |
| #23 | 312 | 322 | 323 | 第 11 块锁定并换块，无消行 |
| #25 | 343 | 353 | 354 | 第 12 块硬降后顶出，0 行 |

这些窗口中，观察到结算时方块仍处于同一生成姿态，没有因模型延迟换块。执行输入与模型选择一致，支持“旧模型＋旧 Harness 没有形成有效放置策略”，不支持“平台偷偷向下操作”。不能仅据这些轨迹判断究竟是模型理解、状态格式还是提示词各占多少原因。其他种子中 A 也会横移、旋转或 hold；不能把这一局的“全硬降”推广到所有旧版请求。

**V8 能形成目标→按键→原生消行链。** 独立 101 的 [V8 对局](http://127.0.0.1:5091/zh/arcade/arcade-06e5d46c-8bdb-4375-8bc6-3f412721bc15)：第 6 块目标为最左列 6、朝向 0。事件 #44 在 tick 2275 观察到该姿态，Decision 选择 `hard-drop:100`，tick 2346 结算，2347 生效并消 1 行、加 100 分。独立 307 的 [V8 对局](http://127.0.0.1:5091/zh/arcade/arcade-7601adf3-ba2e-4597-b0b0-6b88a39432a5) #29 则在目标列 9/朝向 1 时，1409→1483→1484，原生消 1 行。目标选择本身没有输入事件；没有程序自动补齐移动路线。

**实时延迟仍会使合理方向失效。** 独立 101 V8：

| 事件 | 模型选择 | 观察→结算→生效 tick | 可确认事实 |
| --- | --- | --- | --- |
| #60 | `left:300` | 3099→3173→3174 | 第 7 块位于最左列 8，目标列 6；输入首帧向左到列 7 |
| #62 | `left:100` | 3174→3248→— | 观察时仍是第 7 块、列 7；返回时已换成第 8 块，因此丢弃 |
| #128 | `target:3:1` | 6620→6768→— | 目标请求期间第 14 块从列 1/y7 变为列 4/y10；这是此前输入与自然物理的实际演进，不是目标产生了按键 |
| #129 | `left:100` | 6768→6839→— | 返回时已经是第 15 块，丢弃旧回答 |

独立 307 V8 #114 也出现 6097→6171 的换块丢弃。这里能确认“答案过期且保护正确生效”，不能声称该方向若零延迟必然安全或能到达条件落点。姿态预测不含 SRS 路径和实时可达性证明。

因此，这次收益来自**完整 Harness 迁移后的组合效果**；已排除所核查轨迹中的输入替换/重复执行和回放不一致，但尚未独立区分模型决策能力、表示方式、视觉与延迟的因果贡献。接下来若做消融，应另立协议，不能在本次验收种子上继续调参再宣称独立提升。

## 复现、体验和回滚

从 [本地创建页](http://127.0.0.1:5091/zh/arcade/new?game=tetris) 选择俄罗斯方块、V8、已有 System One 模型，可单 AI 观战、玩家对 AI 或双 AI。自己练习保持原生键盘/触屏操作。已准备一个[尚未开始的 V8 房间](http://127.0.0.1:5091/zh/arcade/arcade-20ce005f-ac86-4f65-9701-74a8f61aefc3)。

版本在创建时冻结，不能局中切换；旧历史不补写成 V8。切回下一局的 `tetris-harness-baseline-v1` 即回滚。现有 Key、账户隔离、预算和恢复保护保留，不自动发布社区或部署生产。

按[运行说明](../../tetris-v8-harness.md#real-experiment)创建新的 plan 文件并显式确认真实调用。不要覆盖已有 plan/ledger；失败或未知结果不会自动重试。读取既有结果不产生模型调用：

```sh
node scripts/tetris-v8-experiment.mjs report --plan artifacts/tetris-v8/acceptance.json
node scripts/tetris-v8-audit.mjs \
  --plan artifacts/tetris-v8/acceptance.json \
  --report artifacts/tetris-v8/acceptance.report.json \
  --auth-file /ABSOLUTE/PATH/TO/YOUR_PROTECTED_ARENA_SESSION.json \
  --output artifacts/tetris-v8/audit-new.json
```

审计只读取本人回放，重新执行已记录的原生输入；输出有限、脱敏的结算窗口到忽略目录。不同时间重新运行模型不会保证得到相同分数。16 局的 1,834 个存储检查点与最终分数均重建一致，所有应用动作都与模型选择一致，所有目标事件均无原生输入。
