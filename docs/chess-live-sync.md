# 棋类实时同步修复（2026-10-18）

适用五子棋、中国象棋、军棋。规则、计分、模型调用和服务端玩家视图均不改动。

## 原因与修复

原页面连接同源 `/api/arena/matches/<id>/socket?seat=...`，但本地 Node HTTP 转发不能中继 WebSocket upgrade，独立 Bridge 又只接收 arcade 路径。棋盘因此退回 3 秒轮询；快速模型的多次落子会在页面合并成一次跳变。

- Vite 将棋类 socket 同源请求转到 5094 的认证 Bridge，保留 Cookie 会话验证、明确 Origin 白名单、服务端推导 owner、runner 内部鉴权及原始 seat 查询。允许 `0`、`1`、`spectator`；新增的 `full` 由 runner 进一步限制为对局所有者观看纯 AI 军棋对局（见下文）。普通棋类 HTTP API 不走此 proxy。现有 Tunnel 的 5091 路由无需变更；正式 Worker 仍走原来的内部 Service Binding。
- 收到首个有效快照后才显示“实时连接”。10 秒没有初始快照会重连；每 10 秒 ping，超过 25 秒无有效消息，在下次检测时重连。失败采用 1/2/4/8/15 秒退避；只恢复订阅，不重发任何游戏命令或模型请求。
- 关闭/换房间/换账号或玩家视图时清理旧连接、定时器和回调。缓存仍按账号、房间、viewer 隔离。HTTP 和 WebSocket 均在写缓存时检查版本，旧响应不能覆盖较新的棋盘或终局状态。
- 保留断线 3 秒轮询、连接正常 15 秒校验的后备机制。开发服务器重启时等待 Bridge 释放端口，避免 5094 被旧监听器占住。

## 复现与验证

运行本地站点后，使用已有、未提交的本地测试账户会话：

```sh
node scripts/smoke-chess-sync.mjs
# 可选：ARENA_CHESS_FIXTURE=/absolute/path/to/private-fixture.json
# 文件仅需包含 cookie 字段；不要提交或粘贴其内容。
```

脚本只接受 loopback HTTP，默认 `http://127.0.0.1:5091`。通过同源端口创建三局私有本地双人测试局，每局走 6 手，验证推送、ping/pong、重连恢复，再结束测试局。不调用模型、不发布社区、不修改已有对局。

实测命令发出到客户端收到对应版本广播（2026-10-18，一次本地样本）：

| 游戏 | 六次延迟，毫秒 | 重连快照 |
| --- | --- | --- |
| 五子棋 | 10, 5, 5, 6, 4, 4 | 通过 |
| 中国象棋 | 6, 6, 6, 6, 5, 5 | 通过 |
| 军棋 | 5, 5, 4, 5, 6, 6 | 通过 |

以上是本地 HTTP 命令到 WebSocket 接收的传输测量，不包括浏览器绘制，不代表公网延迟保证。不是模型性能实验。匿名升级返回 401，错误 Origin 返回 403；军棋玩家只看到本方身份，观众不能看到任何未揭示身份。Chrome 中既有军棋房间刷新后显示“实时连接”。

开发服务热重载验证：Vite 确认 `server restarted`，未再出现 5094 占用。随后再次各走 6 手，五子棋延迟为 7/5/5/6/8/6ms，象棋 8/7/7/7/11/6ms，军棋 7/6/6/5/5/6ms；重连、心跳及隐藏视图检查再次通过。

`apps/web/tests/ui/match-sync.test.ts` 覆盖 HTTP/推送竞态、终局倒退、账号与视图缓存隔离、断线/握手超时/静默连接、退避及清理。Bridge 测试覆盖玩家参数、伪造 owner、非法 Origin、匿名请求和开发重启释放端口。运行 `pnpm test`、`pnpm test:runner`、`pnpm typecheck`、`pnpm build`、`pnpm build:cloudflare` 检查回归。

本次结果：`pnpm test` 681 项、`pnpm test:runner` 158 项通过；类型检查、普通构建和 Cloudflare 构建通过。

已完成的对局仍可查看，未改历史回放，也未启动或重试付费 AI 对局。没有部署生产环境。

## 军棋 AI 对 AI 观战视角（2026-10-18）

纯 AI 军棋房间默认选中“全局”，棋盘上方可切换“只看蓝方 / 只看红方”。仅登录的对局所有者可以使用；HTTP 和 WebSocket 均先校验归属。单方视角展示该方已知的身份（包含战斗已揭示的信息），终局后仍遵循同样的视角；全局和正式终局回放展示全部身份。观战投影不提供合法操作列表，也不能当作人类落子。人机对战和本地双人不增加全局入口。

`armyWatchView` 仅用于浏览器快照，模型仍通过原有 `army.observe` 获取本方视野，不读取观战快照。单方视角同时隐藏另一侧的思考和概率记录；切换全局后可查看服务商实际返回的私有记录。公共发布、回放白名单、规则和历史动作数据均不改变。

军棋与象棋的末步提示改成透明边框，避免中心金色方块遮住棋子名称；五子棋的圆点提示保持不变。

新增验证覆盖所有者全局及单方 HTTP/WS、跨账户拒绝、禁止观众落子、两侧模型请求仍为各自视野、终局侧视图与广播、全量回放及视角按钮。Chrome 在既有已结束的 AI 军棋房间验证切换，同时验证人机布阵房间没有该入口。未发起真实模型调用。

观战改动验证结果：`pnpm test` 688 项、`pnpm test:runner` 159 项通过；`pnpm typecheck`、`pnpm build` 和 `pnpm build:cloudflare` 通过。浏览器完成全局→蓝方→红方→全局的检查，金色末步边框不遮挡棋子文字。本地截图位于忽略目录 `artifacts/army-watch-full-2026-10-18.png`。
